# Hindi narration recorder

Records a Hindi reading of the Bhagavad Gita for the Parth app (Addonn), using AI4Bharat Indic Parler-TTS.

- Text: Lokamanya Tilak's Gita Rahasya, Hindi by Madhavrao Sapre, 1916 (public domain).
- The recorded audio is encrypted before it leaves the build machine and is not published here.
